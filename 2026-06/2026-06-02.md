## 🏆 霸主在位

### 1. microsoft/markitdown — 文档转 Markdown 的事实标准
⭐ 138,713 | 🐍 Python | [github.com/microsoft/markitdown](https://github.com/microsoft/markitdown)

微软出品，将 PDF、Word、PPT、Excel 等办公文档一键转为干净 Markdown。原本为 RAG 数据管线而生，现在已成 AI 数据摄取的基础设施级工具。上周刚合并了新的图片 OCR 管线，继续巩固其在「文档→AI」这条链路上的不可替代地位。

⚡ **锐评**：不是最性感的项目，但每一个做 RAG 的人最终都会来到这里。

## 💡 趋势洞察

本周 GitHub AI 领域呈现三条清晰的暗线：

1. **Agent 基础设施从「怎么做」转向「怎么管」** — harness（设计 Agent）、vigils（监控 Agent）、compound-engineering（编排 Agent 流程），共同指向一个判断：单个 Agent 已经够好了，下一阶段的竞争在 Agent 治理层。

2. **AI 编码工具从云端回归终端** — oh-my-pi、vibecode-pro-max-kit 都在强调本地化、隐私和可控性。用户对「代码全上传到云」的忍耐正在见底。

3. **文档与记忆成为新战场** — markitdown（文档摄取）、supermemory（记忆引擎）、vibecode（上下文保持），都在解决 AI 的「失忆」问题。记忆架构可能是 2026 下半年最大的差异化赛道。
