## 维护索引

需要 Python 3.9 或更新版本，无第三方依赖。提交新文章后运行：

```sh
python3 scripts/build_index.py
python3 scripts/build_index.py --check
python3 -m unittest discover -s scripts -p 'test_*.py'
```

文件格式为 `YYYY-MM/YYYY-MM-DD.md`。索引按真实文件日期倒序生成，每份文件只出现一次；不会虚构缺失日期，也不会将文章内标题当作已核实的新闻。README 中两个 archive 标记之间由脚本维护。

外部发布任务需在提交前调用生成脚本，并将文章与 README 一起提交。上游采集、去重、来源核验和失败重试仍需在外部流程中维护。
